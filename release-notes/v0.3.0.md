## What's new

- Coughs, sneezes, laughs, cries, breaths and applause are reported even when the voiceprint does not match: `speech_other` carries `event` and `emotion`, never text.
- A recognized text that is only punctuation (e.g. a lone "." for a cough) is sent empty; `final` keeps its event and emotion.
- `--ban-emo-unk`: the emotion `EMO_UNKNOWN` is never reported; the likeliest other emotion is reported instead.
- Client 0.3.2: types for the new `speech_other` fields, and for the hotword fields of `final`, the `command` event and the hotword API (`GET /v1/hotwords`, `POST /v1/hotwords/reload`).

## Changed

- Every utterance is transcribed first and the speaker is checked afterwards, as in FunASR. Owner transcripts are unchanged.
