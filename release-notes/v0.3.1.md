## What's new

- The microphone is opened in the Windows raw processing mode where the device supports it, so Windows audio enhancements (system effects) no longer reach recognition. With enhancements on, coughs and laughs used to come out as `Speech`.
- `--no-raw-capture` keeps the enhancements.
- `/v1/status` and the `device` event report `raw_capture`: whether the current device was opened in the raw mode.

## Changed

- miniaudio carries a small local patch for the raw mode; see `third_party/miniaudio/PATCHES.md`.

## Known issues (beta)

- Once, while the laptop's microphone array was captured in the raw mode, the speakers went silent until they recovered on their own. Not reproduced yet; `--no-raw-capture` avoids the raw mode.
- The agent crashed once when the default microphone switched back after a headset was unplugged; it was restarted automatically. 0.2.2 crashed the same way once, so the cause may predate this release.
