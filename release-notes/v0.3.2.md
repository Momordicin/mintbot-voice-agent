## What's new (preview)

The GPT-SoVITS speech synthesis component is in development. This release only installs it; loading voice models, synthesis and playback come in later releases.

- The client manages the component: `createTtsManager({ root, manifest, port, onState })` returns `status()`, `install({ variant, root })`, `useExisting(dir)`, `checkUpdate({ signal })`, `cancel()` and `dispose()`. See the client README.
- `install` downloads the official GPT-SoVITS Windows package (`v2pro`, which runs v2ProPlus models, or `v5`) with resume, checks its SHA-256 and free space, extracts it and test-runs its API before the install counts as done. An interrupted install is picked up again on the next attempt.
- `useExisting` accepts a GPT-SoVITS folder the user already downloaded after the same test run, and never writes into it.
- `checkUpdate` reads the package pins on demand; installing the same variant again replaces an outdated package and removes the old folder only after success.

## Changed

- The release manifest has a new `tts` section with the pinned GPT-SoVITS packages (from `tools/tts_packages.json`).
- The client is 0.3.3 and has its first runtime dependency, `7zip-bin`, for the 7z packages.
- The agent binary and its REST / SSE API are unchanged; only the reported version moves to 0.3.2.
